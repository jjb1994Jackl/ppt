Cross-border AI Skill System

把跨境电商调研，固化成一套可复用的 AI 作战流程

三个 Skill 串起“找数据、判机会、做转化”全链路，让产品调研不再靠临时发挥，而是一次输入，稳定产出老板能看、运营能用、销售能跟进的资料包。

竞品抓取 市场机会 评论洞察 内容脚本 询盘话术
Problem

过去的问题：每次做产品分析，都像从零开始搭棚子

关键词、平台、竞品、价格、评论、脚本、汇报材料分散在不同任务里，输出质量依赖临场描述，难以复用。

信息碎片化竞品链接、视频、评论、市场趋势、供应商信息没有固定承接结构。
判断不稳定爆款、机会、风险、优先级如果没有规则，很容易靠感觉下结论。
转化链路断开调研报告看完后，还要重新写详情页、脚本、达人 Brief、询盘话术。
System Architecture

解决方案：三段式 Skill，把跨境工作流变成标准管线

Skill 01

竞品与爆款内容抓取分析

  • 抓 Amazon、TikTok、Alibaba、Google 等公开信息
  • 整理竞品、视频、达人、供应商链接
  • 判断一级爆款、二级爆款、潜力内容
  • 输出数据表、分析报告、PPT 大纲
Skill 02

市场分析与机会判断

  • 判断产品是否适合跨境销售
  • 对比国家、平台、价格带和进入难度
  • 输出机会等级、风险、90 天计划
  • 形成老板汇报用市场报告
Skill 03

评论洞察与内容脚本生成

  • 分析评论、差评、痛点和真实需求
  • 提炼卖点、优化详情页和主图方向
  • 生成短视频脚本、达人 Brief、询盘话术
  • 把调研变成能直接执行的素材
Skill 01

第一段：先回答“谁在卖，谁卖得好，哪些内容爆了”

它负责把市场里的外部信号抓回来，形成可筛选、可排序、可复盘的数据底座。

Skill 02

第二段：再回答“这个市场值不值得做，先从哪里打进去”

它把产品从“看起来不错”推进到“是否值得投入资源”，并给出国家、平台、价格、包装、风险和阶段计划。

国家机会评分市场需求、平台成熟度、消费能力、物流、合规、竞争、内容传播、B端采购合计 100 分。
平台进入建议Amazon 做复购和评价，TikTok 做内容转化，Alibaba 做 B端询盘，独立站做信任和承接。
价格与规格C端按每 100g、组合装、家庭装分析；B端按 MOQ、FOB、箱规、交期分析。
风险与节奏输出机会等级、合规风险、价格战风险、90 天执行计划和 6 个月增长路径。
Skill 03

第三段：最后回答“怎么改产品、怎么写页面、怎么拍视频、怎么回复客户”

它把评论和竞品页面里的真实语言转成运营动作，把调研结果落到转化素材上。

评论洞察正负面占比、购买原因、差评归因、高频需求、可复用用户表达。
产品优化规格、包装、材质、口味、价格、主图、详情页、平台上架建议。
内容生成Amazon 五点、Alibaba 详情页、TikTok 文案、短视频脚本、达人 Brief、B端询盘话术。
One Command

最终使用方式：一句话调用，固定产出资料包

请按顺序执行三个跨境电商 Skill：产品 apple chips，目标市场美国，平台 Amazon、TikTok Shop、Alibaba.com、Google，业务模式 C端零售 + B端批发，输出完整资料包。

自动扩展关键词 自动抓取/整理公开数据 自动判断机会等级 自动生成内容素材

Decision Layer

它不只是整理资料，而是把判断规则写进流程

爆款、市场、风险、优先级都有明确评分或分级标准，减少“凭感觉做决定”。

爆款判断TikTok 看点赞、评论、分享、购买意图；Amazon 看评分、评论数、BSR 和复购属性；Alibaba 看 MOQ、价格、认证、详情页专业度。
机会判断国家市场按 100 分评分，平台按业务模式和进入难度判断，最终给出 S / A / B / C 机会等级。
转化判断评论语言必须能追溯到真实需求，卖点必须来自评论、竞品页面或产品事实。
Operating Rhythm

建议的团队使用节奏：每个新品都跑一遍，形成内部资产库

Day 1
选品初筛执行 Skill 01 + Skill 02，确认竞品、热度、国家、平台和机会等级。
Day 2-3
素材转化执行 Skill 03，生成详情页、短视频、达人 Brief、询盘话术。
Day 4-7
小步测试上架测试版、找达人、发询盘、跑内容，记录真实反馈。
Month 1
复盘迭代用评论和询盘反向修正包装、价格、主图、话术。
Month 2-3
扩大投放保留高转化脚本，复制达人类型，沉淀平台关键词。
Month 4-6
资产沉淀把报告、脚本、报价、FAQ、页面素材变成产品知识库。
Management Value

对老板来说，价值是把“能不能做”讲清楚

每个产品最后都能得到一套统一口径：市场是否值得进入，先做哪个平台，价格和包装怎么定，风险在哪里，下一步资源怎么投。

决策更快从临时调研变成固定流程，减少反复解释和等待。
汇报更稳每次都输出同样结构的市场报告、评分表和 PPT 大纲。
执行更直接运营、设计、内容、销售都能拿到自己的下一步动作。
Closing

这套 Skill 的本质：把跨境电商经验，变成可复制的工作系统

未来每一个新品，都可以按同样方式跑：先找证据，再判断机会，最后生成执行素材。不是一次性报告，而是一条持续增长的产品分析流水线。
