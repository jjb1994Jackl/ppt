Cross-border AI Skill System

把跨境电商调研，固化成一套可信的 AI 作战流程

三个 Skill 串起“核验证据、判断交付、生成转化素材”全链路。新版流程不只追求快，更强调数据可追溯、机会可解释、执行动作能落到产品和客户开发上。

数据可信度 竞品抓取 交付模型 产品匹配 内容转化
Problem

过去的问题：有数据不等于有依据，有需求不等于能进入

跨境选品最怕两件事：把估算当事实，把市场热度当成公司能做。新版 Skill 把数据边界、交付要求和我方匹配度都写进流程。

数据边界不清公开页面、用户提供、官方来源、推断估算混在一起，容易把不可验证信息讲成确定结论。
交付模型缺失只说推荐 Amazon、TikTok 或 Alibaba 不够，还要回答包装、标签、认证、物流、库存和报价怎么承接。
B端和C端混用B端应看样品、询盘、试订单和复购信号；C端才谈小批量测试、达人测品和投流指标。
System Architecture

解决方案：三段式 Skill，把调研变成“证据到动作”的标准管线

Skill 01

竞品与爆款内容核验

  • 抓 Amazon、TikTok、Alibaba、Google 等公开信息
  • 给每条数据标注来源、类型、可信度和限制
  • 区分已观察事实、推断、估算和未核验信息
  • 输出竞品、内容、供应商候选和数据缺口
Skill 02

市场机会与交付模型判断

  • 判断目标国家、平台、价格带和进入难度
  • 明确 B端进口商、分销、OEM 或 C端平台打法
  • 加入食品合规、标签、保质期和物流风险初筛
  • 输出我方产品匹配度和进入优先级
Skill 03

评论洞察与内容脚本生成

  • 分析评论、差评、痛点和真实需求
  • 提炼卖点、优化详情页和主图方向
  • 生成短视频脚本、达人 Brief、询盘话术
  • 把已核验洞察转成能直接执行的素材
Skill 01

第一段：先回答“信息从哪来，能信到什么程度”

新版 Skill 01 不再只抓链接和热度，还会给每条数据打上证据标签，让后续报告知道哪些是事实，哪些只是推断。

Skill 02

第二段：再回答“这个机会要用哪种生意打法承接”

新版 Skill 02 把市场机会拆成目标市场、渠道、交付模型、我方产品匹配和验证路径，避免只看热度就投入资源。

目标市场交付模型判断应走 B端进口商、分销批发、OEM/ODM、Amazon、TikTok Shop、独立站询盘或展会样品开发。
食品合规与标签风险初筛进口规则、营养成分表、配料表、过敏原、声明风险、保质期、仓储和平台禁限售。
我方产品匹配度看现有产品、包装、认证、标签、成本毛利、MOQ、交期和复购是否匹配目标打法。
B端验证与C端测试B端看样品、报价、试订单和复购；C端看价格、包装、达人内容、CTR、CVR、ROAS 和评价。
Skill 03

第三段：最后回答“怎么改产品、怎么写页面、怎么拍视频、怎么回复客户”

它把评论和竞品页面里的真实语言转成运营动作，但素材必须回到可追溯的评论、竞品页面或产品事实。

评论洞察正负面占比、购买原因、差评归因、高频需求、可复用用户表达。
产品优化规格、包装、口味、价格、主图、详情页、平台上架建议，尤其关注食品品类的口感、密封和保质期反馈。
内容生成Amazon 五点、Alibaba 详情页、TikTok 文案、短视频脚本、达人 Brief、B端询盘话术。
One Command

最终使用方式：一句话调用，但输出必须带证据边界

请按顺序执行三个跨境电商 Skill：产品 apple chips，目标市场美国，平台 Amazon、TikTok Shop、Alibaba.com、Google，区分 observed、inferred、estimated 和 unverified，输出完整资料包。

Decision Layer

它不只是整理资料，而是把“不能乱说”的规则写进流程

新版 Skill 的核心不是制造更漂亮的结论，而是让每个结论都知道自己的证据等级、适用范围和下一步验证方式。

事实分层observed、official、user_provided 可以作为强证据；inferred、estimated、limited_access、unverified 必须写明限制。
机会分层市场需求、平台热度、交付模型、我方产品匹配度分开判断，最终再给 S / A / B / C 机会等级。
执行分层B端输出样品验证、报价问题和买家跟进；C端输出测试价格、包装、内容角度和放量条件。
Operating Rhythm

建议的团队使用节奏：每个新品都先过证据关，再进入执行

Day 1
证据盘点执行 Skill 01，整理公开数据、来源日志、访问限制和数据缺口。
Day 2
机会判断执行 Skill 02，确认目标市场、交付模型、食品合规风险和我方匹配度。
Day 3
素材转化执行 Skill 03，把已核验洞察转成详情页、脚本、达人 Brief 和询盘话术。
Week 1
B/C 分流B端发样品和询盘，C端做内容和小批测试，分别记录成功信号。
Month 1
复盘迭代用询盘、样品反馈、评论和投放数据修正包装、价格、标签和话术。
Month 2-3
资产沉淀把报告、证据表、报价问题、FAQ 和脚本变成产品知识库。
Management Value

对老板来说，价值是把“能不能做、凭什么做、怎么做”讲清楚

每个产品最后都能得到一套统一口径：哪些信息已核验，目标市场需要什么交付模型，我们现有产品是否匹配，下一步应该验证 B端还是测试 C端。

风险更透明销量、GMV、产能、份额没有可靠来源就不写成事实，报告会直接标出数据缺口。
汇报更稳市场机会、交付模型、合规标签、产品匹配和 B/C 路径都有固定结构。
执行更直接供应链、销售、运营、内容团队都能拿到自己的核验问题和下一步动作。
Closing

这套 Skill 的本质：把跨境电商经验，变成可复核的工作系统

未来每一个新品，都可以按同样方式跑：先核验证据，再判断交付模型和产品匹配，最后生成执行素材。不是一次性报告，而是一条能持续复盘的产品分析流水线。
